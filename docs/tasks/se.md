# Speech Enhancement (SE)

This section explains the SE task in SoundKit...

## Features
- Noise suppression
- Real-time inference
## Install SoundKit

```bash
pip install soundkit
```

Einstein's formula is $E = mc^2$
!!! note "Model Options"
    === "Export"
        Export allows you to convert models for deployment.

        - Format: `.tflite`, `.c`
        - Supports: quantization, streaming

    === "Demo"
        Demo runs inference on the EVB or in-browser.

        - Interface: CLI, WebUSB
        - Platform: Apollo4, STM32
